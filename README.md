# 👉 NOTE
This repo is implementation for RSP-3DAdv in pytorch.🔥
# 🌀 Introduction
RSP‑3DAdv is an adversarial attack framework for 3D point clouds that preserves object rigidity by perturbing points along surface normals, generating natural and imperceptible adversarial examples that successfully fool PointNet++ on ModelNet40 without creating outlier points.
